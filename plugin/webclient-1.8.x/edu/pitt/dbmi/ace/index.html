Automated Clinical Evidence (ACE)

ACE (part of the ENACT network, built by the University of Pittsburgh PittNAIL lab) is a Next.js web app + Claude multi-agent pipeline that turns a clinician's natural-language clinical question into an executable SHRINE / i2b2 cohort-count query, one reviewable stage at a time.

The pipeline runs five stages with a human-in-the-loop pause after each — the clinician reviews and edits every stage's output, and later stages are forced to use only the confirmed concepts and codes (no agent-invented codes):
  • Intake & Literature Review — validate the question, search PubMed, judge SHRINE suitability.
  • Clinical Concept Extraction — extract conditions / drugs / labs (with value thresholds) / demographics / timing / outcomes.
  • SHRINE Ontology Mapping — map concepts to ICD-10-CM / RxNorm / LOINC / CPT / ATC via a read-only DuckDB ontology (deterministic; the LLM is only a restricted tiebreaker).
  • Query Logic Builder — build inclusion/exclusion logic, cohort arms, temporal constraints.
  • i2b2 / SHRINE XML Compiler — compile to i2b2 XML query artifacts (deterministic).
